[item?id=47809543](https://news.ycombinator.com/item?id=47809543)

Please double press esc to edit your last message or start a new session for Claude Code to assist with a different task. If you are seeing this refusal repeatedly, try running /model claude-sonnet-4-20250514 to switch models.
